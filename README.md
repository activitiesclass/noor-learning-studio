# استوديو نور — إضافة التحاضير

نسخة متخصصة من [استوديو نور الأصلي](https://github.com/sc1561/noor-learning-studio) لمكتبة التحاضير وإضافة تعبئتها في منصة نور. هذا المستودع لا يضم واجهات شرح الدروس للطلاب أو رحلة التعلم أو بنك الأسئلة.

## مكونات المشروع

- `extension/`: إضافة Firefox للتصفح داخل منصة نور، مع لوحة اختيار المنهج والوحدة والدرس واللقاء.
- `content/catalog.json`: المصدر المعتمد للمناهج والتحاضير.
- `admin.html`: صفحة محلية لمراجعة مكتبة المحتوى واستيرادها وتصديرها.
- `index.html`: صفحة تعريف الإضافة وروابط التحميل والتثبيت.
- `downloads/`: حزمة الإضافة الجاهزة للتثبيت.

## للمعلم

1. نزّل [إضافة استوديو نور](downloads/noor-studio-extension-v1.9.1.zip) وفك الضغط.
2. في Firefox افتح `about:debugging` ثم **This Firefox** ثم **Load Temporary Add-on**، واختر `manifest.json` من المجلد.
3. سجّل الدخول إلى منصة نور بنفسك، وافتح نموذج إضافة تحضير فارغًا.
4. افتح لوحة الإضافة، واختر المنهج والوحدة والدرس واللقاء، ثم عاين الحصتين واضغط «تعبئة».
5. راجع الحقول والأهداف والتواريخ والشعب، ثم احفظ يدويًا في نور.

الإضافة تعمل في جلسة Firefox التي فتحها المعلم. لا تطلب كلمة مرور نور ولا تحفظها، ولا تحفظ التحضير أو تنشره آليًا.

## إدارة مكتبة المناهج

افتح `admin.html` عبر GitHub Pages أو شغّل المشروع محليًا عبر `npm run serve`. الصفحة تعرض المناهج والأعداد وتتحقق من حزمة المحتوى. يمكن استيراد ملف JSON أو حزمة تطوير وتصدير حزمة للمراجعة. التعديلات من الصفحة تحفظ في المتصفح وتحتاج إلى مراجعة ودمج في `content/catalog.json` لإصدار نسخة عامة؛ لا تنشر الصفحة التعديلات إلى GitHub تلقائيًا.

لإضافة منهج أو تحضير، راجع [دليل المحتوى](docs/CONTENT-GUIDE.md). ولتشغيل الإضافة في نور، راجع [دليل الإضافة](docs/NOOR.md).

## بناء الحزمة

يتطلب البناء Node.js 18 أو أحدث وPython 3، ولا يحتاج تثبيت حزم خارجية:

```bash
npm run build
```

ينسخ البناء الكتالوج المعتمد إلى ملفات الإضافة، وينشئ حزمة JSON وحزمة ZIP في `downloads/`.

## نطاق النسخة الحالية

- الإضافة مهيأة حاليًا لـ Firefox؛ ملف manifest يستخدم Manifest V2.
- التخزين والتطوير المحليان في المتصفح، ولا يوجد خادم حسابات أو مزامنة.
- الأهداف غير المرصودة في خيارات نور تبقى للمراجعة اليدوية.
- مستخدم GitHub Pages يستطيع الاطلاع على الملفات العامة للمشروع. صفحة الإدارة لا تملك صلاحية النشر إلى المستودع.
