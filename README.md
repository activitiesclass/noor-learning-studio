# استوديو نور — إضافة التحاضير من منتجات رقمية

بوابة متخصصة لإضافة Firefox ومكتبة تحاضير المعلمين لمنصة نور. المشروع لا يقدم واجهات شرح دروس للطلاب أو رحلة تعلم أو بنك أسئلة.

## للمعلم

ابدأ من [صفحة استوديو نور](https://activitiesclass.github.io/noor-learning-studio/) لتنزيل الإضافة واتبع خطوات التثبيت المعروضة. الإضافة الحالية مهيأة لـ Firefox على الكمبيوتر، ويحتاج التثبيت المؤقت إلى إعادة التحميل بعد إغلاق المتصفح. بعد ذلك سجّل الدخول إلى نور بنفسك، وافتح نموذج تحضير فارغًا، واختر التحضير وراجعه ثم احفظ من نور.

[دليل التثبيت والاستخدام](docs/NOOR.md)

لا تطلب الإضافة كلمة مرور نور ولا تحفظ التحضير أو تنشره آليًا.

## مكونات المشروع

- `extension/`: إضافة Firefox ولوحة اختيار المحتوى.
- `content/catalog.json`: المصدر المعتمد لمكتبة المناهج والتحاضير.
- `admin.html`: لوحة مراجعة المحتوى واستيراده وتصديره؛ تحفظ التعديلات محليًا في المتصفح.
- `index.html`: بوابة المنتج والتنزيل ودليل التثبيت.
- `downloads/`: حزم الإضافة والمكتبة الجاهزة.

## تطوير مكتبة المناهج

راجع [دليل بنية المحتوى](docs/CONTENT-GUIDE.md). صفحة الإدارة أداة للمراجعة والتصدير فقط؛ لا ترفع التعديلات إلى GitHub. راجع الملفات المصدرة، ثم حدّث `content/catalog.json` في المستودع وأعد بناء الحزم.

## بناء الحزمة

يتطلب Node.js 18 أو أحدث وPython 3، ولا يحتاج إلى تثبيت حزم خارجية:

```bash
npm run build
```

ينسخ البناء المكتبة إلى ملفات الإضافة وينشئ ملفات ZIP وJSON في `downloads/`.

## الوضع الحالي

- الإضافة تستخدم Firefox Manifest V2، والتثبيت المتاح حاليًا مؤقت.
- صفحة الإدارة محلية ولا تحتوي على خادم حسابات أو مزامنة أو نشر مباشر.
- بعض الأهداف تحتاج إلى مراجعة المعلم ومطابقة خيارات نور قبل الحفظ.
